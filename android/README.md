# Загрузчик видео — Android-приложение

Нативное Android-приложение со встроенным yt-dlp. Не требует сервера, VPN или прокси —
интернет берёт напрямую с телефона (если на телефоне включён VPN — качает и с заблокированных сайтов).

## Возможности

- Вставьте ссылку → превью → выбор качества → MP4/M4A.
- Кнопка **«Поделиться»** в любой соцсети → «Загрузчик» — ссылка подставится и обработается сама.
- Кнопка **очистки (×)** рядом с полем ссылки.
- Кнопка **вставки из буфера** (иконка буфера обмена).
- **Автоподстановка**: если в буфере обмена лежит ссылка на Instagram / TikTok / VK / YouTube —
  она подставится и обработается сразу при открытии приложения.
- Кнопка **«Просмотр»** — скачивает низкокачественную копию во временный кэш и открывает
  встроенный плеер, чтобы посмотреть видео перед скачиванием.
- Файлы сохраняются в **Загрузки/VideoDownloader**.
- Кнопка **«Обновить yt-dlp»** в футере — подтягивает свежий nightly-билд yt-dlp
  (помогает, когда платформа меняет защиту).

## Сборка

Требуется JDK 17 и Android SDK.

```powershell
cd android
.\gradlew.bat assembleDebug
```

Готовый APK: `android\app\build\outputs\apk\debug\app-debug.apk`.

## Установка

```powershell
adb install -r android\app\build\outputs\apk\debug\app-debug.apk
```

или просто скопируйте APK на телефон и откройте (нужно разрешить установку из неизвестных источников).

## Технические детали

- Kotlin + WebView (переиспользует веб-интерфейс из `app/static`, копируется в `android/app/src/main/assets/www`).
- [youtubedl-android](https://github.com/yausername/youtubedl-android) 0.18.1 — Python + yt-dlp + ffmpeg внутри APK.
- JS-мост `AndroidDownloader`: `resolve`, `download`, `preparePreview`, `readClipboard`, `updateYtdlp`.
- Сохранение через MediaStore (Android 10+) либо напрямую в `Downloads` (Android 9 и ниже).
- Превью-плеер: `VideoView` поверх WebView, файл во временном кэше, удаляется после просмотра.
- Share-intent (`ACTION_SEND`) с авто-извлечением ссылки из текста.

## Замеченные ограничения

- YouTube может отвечать «Sign in to confirm you're not a bot» — это блокировка на уровне IP,
  не ошибка приложения. Помогает смена сети/VPN или обновление yt-dlp.
- TikTok API иногда отвечают медленно — просто повторите попытку.

## Сеть и VPN (Киберпортал X / INCY / ByeDPI и т.п.)

Приложение автоматически находит локальный прокси VPN/DPI-клиента (socks5 127.0.0.1:1080, http 127.0.0.1:7890)
и запускает запрос параллельно по всем маршрутам — берёт первый успешный. Удачный маршрут кэшируется по хосту,
поэтому повторные запросы к той же платформе выполняются за секунды.

Если платформа недоступна со всех маршрутов — она заблокирована и на прямом IP, и с выхода VPN
(например, TikTok банит IP WARP). Тогда поможет только смена сервера в VPN-клиенте.
